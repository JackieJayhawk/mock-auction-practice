# Mock Auction Practice

A free browser-based bilingual auctioneer training simulator by Pan Jackie Liu.

**Live site:** https://auction.panjackieliu.com/

Practice live bid calling with CNY and HKD ladders, bidder switching, bilingual lot copy, prompt scaffolding, draggable/resizable practice modules, and hammer-down sequences.

The app runs entirely in the browser. Practice lots, bidders, and workspace layout are saved locally in the browser.
